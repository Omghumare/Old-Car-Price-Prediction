# Old-Car-Price-Prediction
Car Price Prediction ML Project

This project is a Machine Learning web app built using Python and Streamlit to predict car prices based on car details.

Features
Predicts car price
Streamlit web interface
Machine Learning model integration
User-friendly input options
Technologies Used
Python
Pandas
NumPy
Streamlit
Scikit-learn
Files
app.py → Main Streamlit application
code.ipynb → Model training notebook
model.pkl → Saved ML model
Cardetails.csv → Dataset
